# Speech Therapy — Patient App

> Clean web app prototype designed for speech therapy and clinical rehabilitation services, centred on a patient home-exercise programme.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Speech therapy & clinical rehabilitation

Clean web app prototype designed for speech therapy and clinical rehabilitation services, centred on a patient home-exercise programme.

**Highlights**

- Daily prescribed exercise with guided steps
- Weekly progress tracking of home practice
- Session schedule and therapist contact

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
